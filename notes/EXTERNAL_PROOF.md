## Pin rule — Rekor / GitHub inclusion (deferred)

A local Cosign/SLSA bundle hash or `repos/registry.json` status string is **not** a pin.

Refuse `external-proof-adapted` writeback (when `factory_meter_mode=external_proof`) unless `proof_pin` has:

1. content-addressed `bundle_digest`, **and**
2. public inclusion handle: Sigstore `verificationMaterial.tlogEntries[].inclusionProof` with a **signed C2SP checkpoint** (`checkpoint.envelope`) that verifies offline under a **caller-pinned** Rekor log key (Rekor v2 / rekor-tiles). Do **not** trust unverified `inclusionProof.rootHash` / `treeSize` — parse those from the verified checkpoint. **Witness quorum:** inclusion at tree size N alone does not prove absence of fork — require checkpoint co-signatures from a witness quorum ([C2SP tlog-witness](https://github.com/C2SP/C2SP/blob/main/tlog-witness.md)) or GitHub `verifiedTimestamps`. `rekor_verified` alone is not a bundle verdict. Alternates: `inclusionPromise.signedEntryTimestamp` + `logIndex`, or GitHub `GET /repos/{owner}/{repo}/attestations/{subject_digest}` returning `attestations[].bundle` with non-empty `verificationResult.verifiedTimestamps`.

**Alt — SLSA Source VSA (deferred):** a signed Verification Summary Attestation (`https://slsa.dev/verification_summary/v1`) with `verificationResult: PASSED`, expected `verifiedLevels` (e.g. `SLSA_SOURCE_LEVEL_*`), matching `subject.digest` + `resourceUri` may satisfy the pin **only when** hub also binds `verifier.id` to a preconfigured SCS root-of-trust map and checks `subject.annotations.sourceRefs` (branch/tag substitution). Map `bundle_digest` ← VSA envelope / `inputAttestations[].digest`; `policy.digest` pins the verifier policy version. Tooling: `slsa-verifier verify-vsa --subject-digest --verifier-id --resource-uri --verified-level`. Pattern: full SLSA at primary ingestion → attach VSA → writeback verifies VSA signature only. Does not replace checkpoint+witness inside input attestations. Spec: [verifying-source](https://slsa.dev/spec/v1.2/verifying-source) · [VSA](https://slsa.dev/spec/v1.2/verification_summary) · [slsa-verifier](https://github.com/slsa-framework/slsa-verifier) · [ingestion VSA](https://safeguard.sh/resources/blog/provenance-attestation-consumer-workflow).

**Alt — SCITT Transparent Statement / COSE Receipt (deferred):** register a SCITT Signed Statement (`COSE_Sign1` with protected payload type + CWT `iss`/`sub`) at a Transparency Service; refuse writeback until Receipt(s) return. Persist Transparent Statement with unprotected `receipts` (394); verify each Receipt is tagged `COSE_Sign1` with protected `vds` (395) and unprotected `vdp` (396) inclusion proof (`tree_size`, `leaf_index`, `inclusion_path` for RFC9162_SHA256). Optional: require ≥2 Receipts from distinct TS `iss` (multi-TS non-equivocation) without collapsing to Rekor/C2SP formats. Spec: [RFC 9943 SCITT Architecture](https://www.rfc-editor.org/rfc/rfc9943.html) · [RFC 9942 COSE Receipts](https://www.rfc-editor.org/rfc/rfc9942.html).

**Alt — Sigstore TrustedRoot TUF (deferred):** refuse writeback unless verification uses a TUF-fetched TrustedRoot (`mediaType` `application/vnd.dev.sigstore.trustedroot.v0.2+json`) from `https://tuf-repo-cdn.sigstore.dev` (initialize TUF client from Sigstore root-signing **iteration 5** — backwards-incompatible). Pass via `cosign verify* --trusted-root`; optional SigningConfig `application/vnd.dev.sigstore.signingconfig.v0.2+json` for sign path. Raw Fulcio `GET /api/v2/trustBundle` PEM dumps or hand-assembled cert files **without** TUF are not a root-of-trust pin. Orthogonal to Rekor inclusion proofs, Source VSA, SCITT Receipts, Harbor `bundle_digest`. Spec: [sigstore_trustroot.proto](https://github.com/sigstore/protobuf-specs/blob/main/protos/sigstore_trustroot.proto) · [public deployment](https://github.com/sigstore/architecture-docs/blob/main/sigstore-public-deployment-spec.md) · [cosign custom components](https://docs.sigstore.dev/cosign/system_config/custom_components/) · [fulcio trustBundle](https://github.com/sigstore/fulcio).

Refs: [Sigstore bundle](https://docs.sigstore.dev/about/bundle/) · [rekor-tiles CLIENTS.md](https://github.com/sigstore/rekor-tiles/blob/main/CLIENTS.md) · [Rekor v2 spec](https://github.com/sigstore/architecture-docs/blob/main/rekor-v2-spec.md) · [C2SP tlog-checkpoint](https://github.com/C2SP/C2SP/blob/main/tlog-checkpoint.md) · [GitHub attestations REST](https://docs.github.com/en/rest/repos/attestations) · Cosign `--insecure-ignore-tlog` (not a pin).

Parked until meter=`external_proof`. Needle: `scripts/automation_adapt.py` `prove_next_relay` writeback.
